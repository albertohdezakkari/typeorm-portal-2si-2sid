05 · Cinco casos CRUD con curl

07 · Consultas ORM en mi caso

En cada práctica: compara el SQL con QueryBuilder, observa el método completo del Service, la ruta del Controller y la petición curl. Los valores de la URL llegan al Repository mediante parámetros; el ORM usa las relaciones declaradas en tus Entities.

08 · Entregar el proyecto

Sube a tu repositorio GitHub el backend que has construido y las pruebas de los cinco casos.

  1. Guarda los comandos curl, sus respuestas reales y las consultas SQL antes y después en evidencias/caso-1.txt hasta evidencias/caso-5.txt.
  2. Incluye el código fuente, la configuración de ejemplo y el SQL para preparar tus tablas. Excluye node_modules, dist y credenciales reales.
  3. Haz commit y push. Abre GitHub y comprueba que se ven tus últimos cambios.
  4. Abre el formulario, selecciona tu nombre en la lista del grupo, indica tu correo institucional y pega la URL raíz del repositorio.

Para guardar una prueba, añade | tee -a evidencias/caso-1.txt al curl correspondiente después de crear la carpeta con mkdir -p evidencias. Usa un archivo por caso; conserva también las comprobaciones SQL realizadas.
