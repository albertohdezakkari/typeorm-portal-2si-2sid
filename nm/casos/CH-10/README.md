# CH-10 · Habitaciones y enfermeros · relación N:M

En el [cuaderno de clase](https://albertohdezakkari.github.io/typeorm-portal-2si-2sid/), elige tu correo. Prepara el proyecto base siguiendo detenidamente su README y continúa en Entrenar con mis fichas.

Primero completa la relación 1:N de Hospital → Habitacion. Después amplía el mismo backend con Enfermero y Asignacion. En Nest se crean las dos Entities, un único AsignacionesModule, un AsignacionesService con los tres repositorios y un AsignacionesController para toda la N:M; las altas se hacen mediante la API, con sus IDs reales, sin otra precarga. Serverless conserva sus tablas, Table + Entity y las operaciones desde el modelo.

Lee y copia los archivos completos en orden. Los menús permanecen abiertos, el selector de tecnología está a la derecha y puedes alternar Nest + TypeORM / Serverless + Toolbox. Las comprobaciones se ejecutan en tu terminal. El cuaderno guarda el avance en este navegador.
