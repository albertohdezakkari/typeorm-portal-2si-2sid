# Tienda → Articulo · API Serverless

Continúa la base Serverless 3 y su guía de Codespaces. Define las tablas, Table y Entity; prepara Repository, Service y Handler y conecta las rutas en serverless.yml. Todas las altas se hacen mediante POST y los listados mediante GET, desde las funciones que has programado. Conserva los IDs devueltos. No hay inserciones directas ni scripts de carga.
